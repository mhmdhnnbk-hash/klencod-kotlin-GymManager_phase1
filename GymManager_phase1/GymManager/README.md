# إدارة الجيم — المرحلة 1

## التشغيل
1. ثبّت Android Studio (Koala أو أحدث) مع JDK 17.
2. File ▸ Open ▸ اختر مجلد GymManager ▸ انتظر Gradle Sync (يحتاج إنترنت أول مرة).
3. وصّل هاتفًا (USB debugging) أو شغّل Emulator ثم اضغط Run ▶.

## APK للتجربة
Build ▸ Build Bundle(s) / APK(s) ▸ Build APK(s)
الملف: app/build/outputs/apk/debug/app-debug.apk

## الصور
استبدل app/src/main/res/drawable-nodpi/bg_dashboard.png بنفس الاسم.
كل الصور مسجّلة في ui/theme/GymImages.kt.

## الألوان والخطوط
ui/theme/Color.kt و ui/theme/Type.kt
